# Layout variants

Same content in each: three narratives, 20 nodes, 16 edges (of the source's 31 among these nodes; only those the narratives tell), two invented annotations. Which narrative tells which edge, and all statuses, are lab staging, not source. Open a variant folder as a vault. Bases need Obsidian 1.9 or later; no plugins.

Narratives:
- `night-main-break`: scenario, draft, coded depth first.
- `dry-july-allocation-talk`: scenario, draft, coded breadth first (nodes linked, no edges recorded).
- `sensor-first-pitch`: architecture, done.

Variants:
- `variant-a`: edges are pages; Bases as index pages.
- `variant-b`: edges are fields on node pages; generated table index pages.
- `variant-c`: edges are a table on each narrative; Search-query index pages.

Each README lists expected mismatches.
