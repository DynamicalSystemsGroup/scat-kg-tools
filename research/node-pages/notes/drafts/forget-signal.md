**What it is.** One of three signals the infrastructure carries alongside the resource identifier, with new and update ([[what-koi-is-and-the-rid]]). Invoking it changes the data and not the rules that allow it, which is how the architecture narrative keeps it from confusing the operative and constitutive layers ([[the-data-set-and-the-two-layers]]).

**Two ways it is used.** In ordinary use its effect is bounded and expected ([[the-data-set-and-the-two-layers]]). At Metagov one contributor used it for a large footprint, which degraded the data set for others, and was read by the team as subversive and by the contributor as speaking up for the right to be forgotten ([[forget-incident]]). The page does not decide which reading is right.

**What it addresses.** Only one edge: it addresses the right to be forgotten, as the contributor used it ([[forget-incident]]). Which technologies provide it is not told anywhere.

**Thin.** The signal is linked in three narratives but tells an edge in one; the other two use it to describe the architecture, not to say what it is for.
