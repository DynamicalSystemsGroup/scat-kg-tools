# Synthetic vault

A fictional community water cooperative, invented content only, for exercising graph analyses. `vault/` is generated; do not edit it.

Regenerate (from `research/analysis`): `uv run python synth/generate.py`, then `uv run scat check --root synth/vault`. Output is deterministic (fixed seed), uses only the public `scat_kg` API plus file writes, and the vault is committed.

| Pattern | Where |
|---|---|
| Group holds both sides of a conflict | board-volunteers: privacy / visibility, low cost / safe margins |
| Groups on opposite sides | household-members vs farm-irrigators; farm-irrigators vs watershed-stewards |
| Concerns no affordance addresses | predictable maintenance, pupil learning, site visits |
| Group with all concerns unaddressed | school-liaisons |
| Affordances with no technology | reserve-storage-policy, community-asset-fund, operator-training-course |
| Hubs | usage-dashboard (8 concerns); member-portal, sensor-telemetry-platform |
| Shared concerns | drought supply, community voice |
