## Purpose

Bring the release to the chief engineer's walkthrough (`MISSION.md`, User acceptance and Governance): a candidate
staged on Pages and the template, the AI user tests (UA-A) run to their pass bar on the journey J1 to J10, the
walkthrough scripts, and the reviewer's guide rewritten for this release. Words follow `GLOSSARY.md`.

## Goals

- **WP20-G1. The candidate.** Tools and template `dev` agree (pins, docs test), the docs site deploys from `dev` as a
  pre-release, the template is the GitHub template with `dev` as default, and a fresh clone checks clean (R-6).
- **WP20-G2. UA-A, manual path.** At least three testers, all the organiser at the solo-trial stage, varying in
  comfort with tools, most on Haiku with one Sonnet control (UA-A personas), each in a clean environment from the
  Pages preview, running J1 to J10 in a domain of its own and ending in a stated hand-over case with a locked version.
  Rounds to the pass bar: no blocking finding; every finding dispositioned.
- **WP20-G3. UA-A, chat path** (waits for the chief engineer): at least two testers on the chat journey, driven in the
  browser pane by the ACE after his sign-ins, with lab material only, light and human-paced, each ending torn down
  with the key rotated. Planned and briefed now; run in his sittings.
- **WP20-G4. Walkthrough scripts** for the chief engineer's UA-M on both paths: each stage's entry point and what
  "done" looks like, so a session can be split and resumed.
- **WP20-G5. The reviewer's guide** (D-6), rewritten for this release: four sittings, every ACE call with its
  evidence, what is known to be weak (including WP17-U3b if still held, Docker Desktop untested, the items carried
  from D-095).
- **WP20-G6. Cleanup** carried from D-095: unparsable frontmatter left out of whole-vault views silently; two
  architecture sentences for the new refusals.

## Non-goals

- Opening the release PRs (the ACE does that after UA-A passes and the guide is ready).
- Changes to the tool beyond defects UA-A finds against stated requirements.
