## Purpose

The chief engineer, in his inference.coop analysis session (typed by the agent): "svg is a fine output. we should
record that as a learning. we also need to note that this platform currently lacks visual inspection capabilities. that
is OK but it is something we need to note as compared". What is known so far:
- inference.coop shows a tool's PNG to the person, but its model receives nothing from it. It reads an SVG as text
  (`acceptance/walkthroughs/analysis-session-inference-coop.md`, turns 9 and 10).
- Claude's model receives the image (`acceptance/walkthroughs/mvc-loop-claude.md`, D-173).
- The IDE and local LLM paths are documented at our side of the interface; their trials are deferred (D-197).

## Goals

- **WP36-G1. The pros-and-cons page says what each path's model can see.** One row per path: what the person sees,
  what the model receives (the picture, or text only, where tried; for the IDE and local LLM paths, what our side returns, D-197), and what to ask for instead: the table or SVG.
- **WP36-G2. The analysis page says how to read a drawing with a model that cannot see.** Ask for the table, or both
  (WP33's `output`), or SVG. Show with PNG; SVG to save or for a model to read as structure (D-170).
- **WP36-G3. Each claim has a record.** Every "receives" or "does not receive" on the page cites a run record. A path
  with none describes our side of the interface instead (D-197).

## Non-goals

- Changing the tools. WP33 gives every drawing its table.
- Making a model see images.
- The assistant's habits about choosing a format (WP31).

## Open decisions

- **O1, decided (D-197).** The IDE and local LLM paths are not tried in this package, and their rows do not say
  "not tried". They describe our side of the interface: what each tool returns (a PNG as MCP image content, an SVG as
  text, the table as JSON text) and what to ask for when a model cannot see images (D-183). Trials of those paths are
  deferred by the chief engineer to a later package.

None open. Every item was resolved through the decision loop: O1 decided (D-197), the Agent's defaults approved
(D-198). Counts: decided 2, deferred 0, raised 0.

An organiser choosing a path knows whether their assistant can look at a drawing, and what to ask for when it cannot.

## Agent's defaults
