## Purpose

Make the vault a facilitator-analyst clones. It holds the skeleton the contracts require and a small worked example,
which is this project as its own case study. The example is minimal, because users overwrite it, but it covers
every class.

## Goals

- **WP6-G1. Skeleton.** The folders, class pages and instance configuration (the stakeholder-group cap, set to 3), as
  the contracts specify. Obsidian page templates for the four record types, built from the contracts' skeletons
  (section 5), with the minimal Obsidian settings WP6-R7 needs.
- **WP6-G2. Tools pinned.** A uv project that installs `scat-kg-tools` as a git dependency pinned to a commit, and
  one documented setup command.
- **WP6-G3. The case study.** The elicitation of scat-kg itself:
  - **Instances:** 2–3 of each of the seven classes.
  - **Records:** two scenarios and two architectures, each raw and coded. One scenario is the false start, rollback
    and clean restart from log D-020.
  - **The conflict:** anonymity versus attribution as a concern conflict, which shows `SCAT-CONFLICT-BOTH` (D-032).
  - **Sources:** content comes only from the chief engineer's recorded statements and the decision log.
  - **Chatham House:** stakeholder groups are named by role, and none stands for one identifiable person.
  - **Tone:** no politically loaded illustrations.
- **WP6-G4. README.** It says what the vault is, recommends a private repository, and gives the creation path with
  private visibility pre-selected where GitHub allows it (R-12). It links to the docs site for the guides instead of
  copying them.

## Non-goals

- The tools (WP5) and the docs site (WP7).
- The candidate stage: marking the repository as a template and setting the default branch belong to WP8.
- Any content not traceable to the chief engineer's statements or the decision log.

## Definition of good

A newcomer opens the vault in Obsidian and understands SCAT from the example alone, and the example is small enough
to delete in one go.

## Definition of good enough

WP6-R1 to WP6-R7 are met.

## Blast radius

In `scat-kg-template` only: the vault folders, `scat.toml`, `.obsidian/**`, the page-template folder, `README.md`,
`pyproject.toml`, `uv.lock`, `.python-version`, `.github/**` and `.gitignore`. (The PM owns the board.)
`contracts/` and `ontology/` are read-only for WP6, and any gap in a contract or a tool goes to the ACE.
The PM makes one bootstrap commit on `main`, a README stub, so that `dev` can be branched (log D-033).
