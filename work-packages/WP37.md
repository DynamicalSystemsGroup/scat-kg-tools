## Purpose

The chief engineer (D-173, typed by the agent): "i have decided that i want my app to be named scatlab (its meant to
make someone think of matlab. its for scat coding (instead of math coding) and even if we leave it implicit people will
appreciate the easter egg". D-173 leaves open what the rename covers: "the SCAT Chat app, the tool, the repositories,
the docs site".

Today the menu-bar app is **SCAT Chat** (`deploy/SCAT Chat.applescript`, `deploy/scat-chat.sh`). It is named in 40
files of the tools repository, 85 times on `docs/chat-path.md` alone. The command is `scat`, the package `scat_kg`,
the server `scat-mcp`, the docs site's name "SCAT", and the repositories `scat-kg-tools` and `scat-kg-template`. The
lab's server host is already `scat-lab`. SCAT stays the method's name throughout.

## Goals

- **WP37-G1. The named things carry scatlab.** Whatever O1 settles is renamed in code, build, pages and messages.
- **WP37-G2. Nothing breaks for a current user.** An installed SCAT Chat is replaced cleanly: no second app, no leftover
  keychain item, no stale image.
- **WP37-G3. The easter egg stays implicit.** No page explains the name.

## Non-goals

- Renaming the method (SCAT), the ontology or its identifiers.
- Rewriting history: decision records, acceptance records and earlier scopes keep the names they used.
- Anything O1 leaves out.

## Open decisions

- **O1, decided (D-199).** The menu-bar app SCAT Chat becomes **SCATLAB** (the name is reserved for the app; D-201). The
  tools repository `scat-kg-tools` becomes `scat-tools` (the docs site's address moves with it), and the template
  repository `scat-kg-template` becomes `scat-template`. The Python package `scat-kg` becomes `scat-tools` (`scat`
  is taken on PyPI by an unrelated project). The command stays `scat`.
- **O2, decided (D-200).** Before the v0.1 release: v0.1 ships under the new names.

None open. Every item was resolved through the decision loop: O1 (D-199), O2 (D-200), the Agent's defaults
(D-201, with the app's name in capitals). Counts: decided 3, deferred 0, raised 0.

## Definition of good

A new organiser meets one name for the thing they install and run, and an existing one upgrades without noticing more
than the new name.

## Agent's defaults

- **SCATLAB, in capitals, is the app's name** wherever a person reads it (pages, menus, the app's displayed name;
  D-201). Code, tools, the CLI, file names and identifiers stay lower case.
- *(default)* The import name follows the package: `scat_kg` becomes `scat_tools`, with `scat_kg` kept as a thin alias
  for one release. The server command `scat-mcp` keeps its name, like `scat`.
- *(default)* GitHub's redirects from the old repository names are relied on, and the template's pin and every clone
  instruction use the new names.
- *(default)* The on-screen run uses the chief engineer's accounts and keys, with the ACE as coder.
