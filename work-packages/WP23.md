## Purpose

`MISSION.md` (Non-goals, as edited by D-127) now says a vault runs in exactly one **attribution mode**, set by the
organiser at set-up and known to the tools: attribution **required**, **optional** or **disallowed** (the Chatham
House rule); the modes are disjoint and must not bleed together in use; edges and nodes always record groups. The
chief engineer's pilot uses the disallowed mode, and he wants the other two in the software. This package builds the
modes, and renames the TBox's `scat:Attributes` so that "attribution" means only this. Words follow `GLOSSARY.md`; the
terms it adds are under G6.

## Goals

- **WP23-G1. The mode is declared, and known.** Each vault declares its attribution mode in `scat.toml`; the tools read
  it before anything else and report it; a vault with no mode, or an unknown one, is refused by the check with a fix
  that names the three choices. The template declares `disallowed`, with one line saying how to choose another.
- **WP23-G2. The mode is a repository metaparameter that sets the rules (D-133).** The mode changes what is
  conformant, and the assistant's norms. The one mode-dependent rule, stated identically in the ontology's checks, the
  vault check, the docs and the assistant's rules: in **required** mode a narrative SHALL name its contributors; in
  **disallowed** mode it SHALL NOT; in **optional** mode it MAY. "Name" means `attributed_to` links to contributor pages.
  In required mode the rule is graded like other fields `done` needs (a warning before `done`, an error at `done`); in
  disallowed mode any `attributed_to` or contributor page is an error at every status.
- **WP23-G3. Contributor pages in the knowledge graph (D-133, D-134).** Where the mode enables attribution (required or
  optional), each contributor has a page of a new type, `contributor`, outside the four layers; a narrative's
  `attributed_to` field holds links to those pages, and the predicate resolves in the knowledge graph (a dangling link is
  an error, as for any link). Contributor pages never take part in the four layers' edges, the cap, or the layered views
  (fingerprint, edge tables, layered view, trace); an attribution view, `scat attribution` (CLI, Python and an MCP tool, listed in
  `docs/reference/cli.md` and `docs/reference/mcp.md`), lists narratives by contributor. Contributor pages are in the
  knowledge graph but not the layered graph (a glossary change, D-138). In
  disallowed mode no contributor page may exist. A vault whose mode changes is checked whole against the new mode.
- **WP23-G4. The assistant's rules: the deontic pass and the mode (C11, D-133, D-134).** `contracts/assistant.md`
  defines MUST-style keywords once (RFC 2119 sense) and applies the table: MAY for A1 to A4 and A6; SHOULD for A5;
  SHALL NOT for A7 to A12 (A10: it SHALL state the doubt and hand it back); SHALL for A13 to A15; plus the mode rule of
  G2. The skill follows (drift test): SHALL for the edge grammar; SHOULD for one step per reply, offering `kind`,
  offering a description. The MCP server reports the mode on every result; the MCP tool `stub` makes contributor pages
  only where the mode enables attribution.
- **WP23-G5. Set-up and expectations.** The planning guide's set-up stage has the organiser choose the mode and say
  what participants are told; the consent page names the three modes; the coding guide shows contributor pages and the
  field; the norms page states the mode rule as in G2.
- **WP23-G6. Words and the formal name.** The TBox's `scat:Attributes` (affordance to technology, label "is provided
  by") is renamed to a name for "is provided by" everywhere; the glossary gains **attribution mode**,
  **attribution** and **contributor page** (the people a narrative is attributed to, each with a page, where the mode
  allows; the glossary's existing sense of "contributor" as a participant is kept and the two are related) as a logged call with the change consultant's sweep. The ontology's
  `owl:versionInfo` moves from 0.2.0 to 0.3.0 (the published IRI is `https://w3id.org/scat#`).

Candidates: WP23 takes C13 and C11 (D-133). It leaves C9; C12 is WP24, which runs after WP23 (it shares the skill,
the assistant's rules and the page contracts); C14 and C15 are WP25, after WP24 (they share `docs/coding.md`,
`docs/planning.md` and the facilitating pages, which WP23 touches only for the mode).

## Non-goals

- Attribution of edges, the four layers' nodes, or quotations to individuals. Contributor pages attach to narratives only.
- Detecting personal names in a narrative's text (the tool cannot; the norms say what the organiser does).
- Identity management, consent records or contact details for contributors.
- The chat-path launcher and its guides (WP22).

## Definition of good

An organiser chooses one of three modes at set-up, tells participants what it means, and can rely on the tools never
to let a contributor's name appear where the mode forbids it, nor in the knowledge graph at all.

## Definition of good enough

WP23-R1 to R8 met.

## Agent's defaults

- *(default)* The `scat.toml` key is `attribution`, with values `required`, `optional`, `disallowed`; the narrative field
  is `attributed_to`, a list of links to contributor pages.
- *(default)* A missing mode is an error (the system must know the mode), not a silent default; the template ships
  `disallowed`.
- *(default)* The TBox gains a `contributor` page type outside the four layers and an `attributed_to` field on
  narratives linking to it (the `prov:wasAttributedTo` sense), separate from the edge types; D-128 as revised by D-133.
- *(default)* `docs/reference/terms.md`'s cap rises again to fit **contributor page** (D-138).
- *(default)* A contributor page's required fields are `type`, `status` and `title` (a name or handle as the organiser
  records it); nothing else is required.
- *(default)* Pin order, so `dev` never goes red: the tools units merge to an integration branch; the template branch
  pins that integration commit and declares its mode; the integration branch lands on `dev` together with
  `TEMPLATE_COMMIT` pointing at the template commit; then the template's `dev` takes its branch. The test fixtures that
  write `scat.toml` (27 files, through the three helpers) default the mode in the helpers.
- *(default)* The new name for the edge property is `scat:ProvidedBy`.
