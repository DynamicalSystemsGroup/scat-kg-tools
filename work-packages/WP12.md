## Purpose

Give the project manager who coordinates an elicitation event one page to keep open. They supervise the capture of
field notes and are responsible for the data being coded and analysed satisfactorily. The page is a glossary of the
load-bearing terms and the links between them. It shows where each term enters the work: the facilitation plan, the
field notes, the coding, and the analysis that follows (finding F-8, log D-068).

## Goals

- **WP12-G1. The page.** `docs/reference/terms.md`, titled "Terms", under Reference in the nav. Each entry gives:
  - one plain-language definition;
  - what it is in the vault, by page type;
  - the stage where it enters the work: plan, capture, code or analyse;
  - what the project manager can check, in one line where there is one.

  The terms:
  - elicitation, scenario, architecture, stakeholder group, concern, affordance, technology;
  - the connective tissue between them:
    - the three links (holds, addressed by, attributed to) and a conflict between concerns;
    - raw and coded records;
    - status (stub, draft, done, with done as the sign-off);
    - the past/future mark;
    - a clean check.

  Nothing else.
- **WP12-G2. It can't drift.** A test checks that every page type, link and status value the page names exists in the
  TBox, under the name the page uses.
- **WP12-G3. Findable.** The home page and the planning guide each gain at most one line linking to it.

## Non-goals

- Any new field, rule, check or tool, and any change to the TBox or the contracts.
- Teaching how to facilitate or code: the guides do that, and the page links to them.
- Analysis tooling (a mission non-goal). The page may say what analysis needs: a clean check and signed-off pages.
- Changes to the guides beyond G3's one line each.

## Requirements

| ID | Requirement | Checked by |

| WP12-R1 | The page defines exactly the terms in G1, each once, in at most 600 words, with no term used before it is defined or linked. | Inspection; a word count |

## Definition of good enough

WP12-R1 to WP12-R5 are met, and the ACE has read the page as the coordinating project manager would: someone who never
opens `src/` or `contracts/`.
