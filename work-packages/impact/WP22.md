## Risks

- The drift test breaks if the markers move without the test: change both in one commit.
- Linux CI cannot run AppleScriptObjC or a menu-bar item: stand-ins only; the visual parts wait for the sitting. Keep macOS code in the launcher's own functions (MISSION, Platforms).
- The guides' step rules (D-119) fail on added steps without a place or with two actions.
- Words: the window must say "MCP server", but the glossary's MCP server is a front end to the tool, not part of it.
- The `ps` check (R6) must be re-run after any change to `copy_key` or the new address button.
