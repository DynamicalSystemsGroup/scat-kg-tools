# scpt-kg-tools

Conformance tools, fixed TBox and documentation for SCPT knowledge-graph vaults: elicited scenarios and
architectures, decompiled into stakeholders, concerns, properties and technologies, and related through layered
bipartite graphs. The vault to clone is [`scpt-kg-template`](https://github.com/DynamicalSystemsGroup/scpt-kg-template).

Under construction toward v0.1. See `MISSION.md` once it is merged.
