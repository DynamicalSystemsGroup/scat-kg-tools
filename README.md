# scat-tools

Conformance tools, fixed TBox and documentation for SCAT knowledge-graph vaults: elicited scenarios and
architectures, decompiled into stakeholders, concerns, affordances and technologies, and related through layered
bipartite graphs. The vault to clone is [`scat-template`](https://github.com/DynamicalSystemsGroup/scat-template).

Under construction toward v0.1. See `MISSION.md`.
