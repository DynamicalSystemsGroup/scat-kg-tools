# Coding paths

!!! tip "Your next step"
    Pick the path below that fits your data policy and your tools, then open its walkthrough.

Coding links the nodes a narrative names and records the edges it tells. You can do it four ways. In every one, the
tool checks the result and you own the interpretation; the assistant, where there is one, only helps.

| Path | You work with | Example | Walkthrough |
| --- | --- | --- | --- |
| By hand | Your own editor and a terminal, no AI | none | [Coding](coding.md) |
| An AI chatbot | A chat window in your browser | Claude | [The chat path](chat-path.md) |
| An AI chatbot, strict data policy | A chat that keeps nothing on the platform | inference.coop | [Leave no trace](leave-no-trace.md) |
| An AI IDE | An editor with an agent and a terminal inside it | Codex | [The IDE path](ide.md) |
| A local LLM | A model on your own computer; you supply it | Ollama in Docker | [A local LLM](local-llm.md) |

The examples are examples: each walkthrough names its provider in one place, and another provider of the same kind
works the same way.

## Which path fits

1. Does your data policy ask that nothing leaves your computer? Use **a local LLM**, or **by hand**.
2. Does it allow an AI platform but ask that nothing stays there (non-retention, or an approved chatbot only)? Use
   **an AI chatbot** with **Leave no trace**.
3. Is any AI platform allowed? Use **an AI chatbot** if you prefer a chat window, or **an AI IDE** if you already work
   in an editor with a terminal.
4. Do you want no AI at all? Use **by hand**.

If two paths fit, the tools you already know decide. You can switch path between narratives: the nodes, edges and
checks are the same.
