# Coding paths

!!! tip "Your next step"
    Pick the path below that fits your data policy and your tools, then open its walkthrough.

Coding links the nodes a narrative names and records the edges it tells. There are four paths: by hand, an AI
chatbot (with leave no trace as its variant for a strict data policy), an AI IDE, and a local LLM. In every one, the
tool checks the result and you own the interpretation; the assistant, where there is one, only helps.

| Path (walkthrough) | You work with | Example |
| --- | --- | --- |
| [By hand](coding.md) | Your own editor and a terminal, no AI | none |
| [An AI chatbot](chat-path.md) | A chat window in your browser | Claude |
| [An AI chatbot, leave no trace](leave-no-trace.md) | A chat that keeps nothing on the platform | inference.coop |
| [An AI IDE](ide.md) | An editor with an agent and a terminal inside it | Codex |
| [A local LLM](local-llm.md) | A model on your own computer, which you supply | Ollama in Docker |

Each example is an example: another provider of the same kind works the same way, and each walkthrough names its
provider in one place.

## Which path fits

1. Do you want no AI at all? Use **by hand**.
2. Does your data policy (whether the field notes may leave your Mac) ask that nothing leaves your computer? Use **a local
   LLM**, or **by hand**.
3. Does it allow an AI platform, but ask that nothing stays on the platform afterwards? Use **an AI chatbot**, in its
   **leave no trace** variant (its example is inference.coop).
4. Is any AI platform allowed? Use **an AI chatbot** if you prefer a chat window, or **an AI IDE** if you already work
   in an editor with a terminal.

If two paths fit, the tools you already know decide. You can switch path between narratives: the nodes, edges and
checks are the same.
